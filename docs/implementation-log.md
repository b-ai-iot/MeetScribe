# Implementation history / Lịch sử triển khai

MeetScribe started as an independent Chrome Manifest V3 extension for locally collecting native meeting captions and selected shared-screen images. Google Meet support was followed by Zoom web iframe routing, then persistent appearance settings, per-session output directories and portable ZIP exports.

MeetScribe được phát triển thành tiện ích Chrome Manifest V3 độc lập để thu phụ đề có sẵn và ảnh từ vùng chia sẻ đã chọn, lưu cục bộ. Sau hỗ trợ Google Meet là định tuyến iframe Zoom web, rồi cài đặt giao diện bền vững, nơi lưu riêng từng phiên và xuất ZIP.
