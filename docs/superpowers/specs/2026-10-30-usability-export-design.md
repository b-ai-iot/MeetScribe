# MeetScribe usability and portable export design

User approved scope (2026-10-30): improve existing Chrome extension UI; configurable background transparency; arbitrary local output directory; ZIP suitable for handing to AI; automatically find native Meet/Zoom caption containers with manual fallback. User requests implementation by AGY Gemini 3.8 Flash High with highest permissions; Codex supervises and verifies.

## Approach
Extend existing vanilla MV3 extension; retain journal-first IndexedDB persistence and downloads fallback. Use a settings extension page for user-gesture directory selection and permission requests; persist directory handles in IndexedDB, verify actual write support in Chrome. Worker writes already-journaled files via a destination adapter; never discard backup on export errors. Configure next-session destination only, preserve old session paths and metadata; do not silently route a denied custom destination elsewhere. No native helper or absolute path text box that falsely promises file access.

## Requirements
- Vietnamese copy; local assets; no AI calls, audio, video recording, new broad host grants, or changes to old collector/skill/source ENFARM checkout.
- Opacity means background alpha only, 40–100%, default current 96%; text stays opaque. Font size 12–18px default 14; remember toolbar position/compact state and reset. Controls labeled and keyboard usable, responsive at 375px.
- Settings accessible from toolbar and library; save/reset feedback, show destination and grant state. Arbitrary directory picker is user initiated. Cancel leaves prior choice intact. Revoked permission retains pending exports and explains reauthorization. Reload retains handle; changing destination affects subsequent sessions. Keep Downloads option. Verify readwrite permission from settings, no repeated picker for every journal part.
- Per-session ZIP from all journal files including already exported data; finalized sessions only, active sessions offer stop-and-export. Include raw JSONL, PNGs, events and metadata, transcript.md (timestamped snapshots, explicitly not deduplicated verbatim speech), README-for-AI.md with cautions and a meeting-note prompt, manifest listing entries. Display progress/error/retry, permit choosing where ZIP is saved. ZIP must extract with standard Python zipfile/unzip; Unicode and binary contents preserved, safe names, memory bounded/error for oversize.
- Improve automatic caption detection by platform-specific semantic/known selectors and visibility; avoid whole-page/chat text; confidence and ambiguity fallback. Highlight detected region with sample text on request. Reacquire hidden/disconnected/replaced container during active collection; no loss on simple rerender and no duplicate reset spam. Native captions must be enabled; silence isn't a missing source. Manual override retained while valid. Never enable captions or send messages in real meetings without user action.
- Library search name/date, rename display title (do not relocate files), preview caption/images, backup size, delete only stopped sessions with explicit confirmation; truthful export state, no XSS from captions/titles.

## Validation and limits
Baseline 18 unit tests pass. Add focused behavioral tests first, run unit + browser + unpacked-extension tests in isolated test browser profile. Cover revoked permissions, canceled picker, existing journal migration, ZIP completeness/binary/Unicode, hidden/replaced/ambiguous caption regions, bounds/reset, keyboard UI and narrow viewport. Never claim real Meet/Zoom or directory persistence beyond what actually tested. Finish with a package and verification doc.
