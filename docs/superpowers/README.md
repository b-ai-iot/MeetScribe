# Historical implementation notes / Ghi chép triển khai

This directory preserves implementation plans, review findings and decisions from development. Most records are in Vietnamese. Resolved findings and temporary review commands are historical; they are not current setup instructions. Temporary machine paths have been anonymized. Use the maintained [English and Vietnamese documentation](../README.md) for installation, operation, development and known limits.

Thư mục này lưu kế hoạch, phát hiện rà soát và quyết định trong quá trình phát triển. Phần lớn ghi chép bằng tiếng Việt. Các lỗi đã sửa và lệnh kiểm tra tạm chỉ có giá trị lịch sử, không phải hướng dẫn cài đặt hiện hành. Đường dẫn máy cá nhân đã được ẩn danh. Dùng bộ [tài liệu tiếng Anh và tiếng Việt](../README.md) được duy trì cho cài đặt, sử dụng, phát triển và các giới hạn đã biết.
